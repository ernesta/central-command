Changes in round 5

  • Priority is P1 / P2 / P3, one family: solid accent for P1, a tint of the same colour for P2, a quiet grey for P3. It stays a column, so it can be sorted and filtered. Subtasks carry none.
  • The row stripe is kept for two other jobs, both visible here: a stripe on the task your timer is running on (the first row, matching the timer in the top bar), and a thread that runs from a task down its subtasks.
  • Subtasks have one control: a pill after the title that shows the count and fills as they are done (0/6). Click it to open or close them. A task with none shows a faint "+ Subtask" in the same place when you hover it. No chevron, no ring, no plus at the far end. Open subtasks hang off a thread, with a plain "+ Add a subtask" line at the end. A subtask cannot have subtasks.
