Opening a top-level list: its sublists' tasks

Opening a list (a landing card) shows every open task in it and in all its sublists. Four ways to lay that out, on the same invented Study 2 tasks. Opening a sublist chip still shows just that sublist, in every option.

Option A

One flat table, a Sublist column

Simplest. Same table and sorting as All tasks; each row says which sublist it is in (blank for tasks directly in the list). Sort by Sublist if you want them together. Nothing new to learn.

Option C

Flat table, sublist chips to narrow it

Opens on All (every task in every sublist, one order by due date, Sublist column as in A). The chips, same look as on the landing cards, narrow to one sublist with a click, which is what the existing "List › Sublist" filter does but without opening a menu.

Flat by default, "Group by sublist" switch
