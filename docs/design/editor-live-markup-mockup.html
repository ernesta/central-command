Notes editor: today and proposed

Left: how the editor behaves now. Right: the Typora way. The one rule on the right: the text you edit is the Markdown itself. The block or word under the cursor shows its markers (in this colour), everything else is drawn formatted. Markers are ordinary characters, so you select, copy, delete and type them like any other text.

What else changes

Files: what is in the editor is exactly what is in the file. Opening never rewrites a note, and your own spacing and bullet characters are left alone (today the editor may normalise * bullets and escapes when you first edit).
Undo: plain text undo, no format steps hidden in between.
Find: matches the Markdown text, so a word inside **bold** is found; searching for stars finds stars.
Paste: plain text always, from Word and the web too (formatting is not kept, for now).
Tables: shown as a grid away from the cursor, as pipes while you are in the table.
