2. Changing a name or initials updates your notes (asked first, with counts)

Change name?

Kathy Rastle → Kathryn Rastle

  • Attendee in 41 meetings
  • Lead in 2 trainings

Only the attendee and lead lines at the top of each note change. Each file is backed up first. A file that changed in the meantime is skipped and listed.

Change initials?

KR → KRa

  • TODO(KR) in 17 TODOs across 9 meetings

Only the owner inside a TODO marker changes ("TODO(KR & EO)" becomes "TODO(KRa & EO)"); no other text is touched. Nothing to update? Only the list changes.

"Change the list only" is there for the rare case where you want old notes left alone (the old name then shows as an outlined chip).
