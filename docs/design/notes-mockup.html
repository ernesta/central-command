4. Quick capture: ⌘ ⇧ N from anywhere in the app

1. You are anywhere, for example reading a paper
Lopukhina et al. (2024) Reading detail…
2. The shortcut makes a new note at once and opens it, ready to type
Untitled Ungrouped Check whether the effect holds for bilinguals
3. Back (⌘ [) returns to the paper; the note is in Ungrouped
Ungrouped Check whether the effect holds for bilinguals Sep 25
New note⌘ ⇧ N
Listed in Settings → Keyboard shortcuts, like every shortcut.

The cursor starts in the body, so you can type first and title later. A note without a title shows its first line in lists. On a group page the new note starts in that group. Ask: should the shortcut also work when Central Command is in the background (a system-wide shortcut)? That is a bigger step; I have left it out of the first version.
