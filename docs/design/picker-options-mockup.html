One way to pick from a list

Two ways to make every picker in the app type to search, shown on the three kinds you have today. Each demo works: click it, type, use the arrow keys and Enter.

What I would build under either option

  • One shared picker replaces DescribedSelect, SkillsField's menu, the people menu and Group's menu. Same open, filter, keys, highlight and empty text everywhere.
  • Search appears only above 7 options. Short lists open as a plain list, still with arrow keys and type-ahead. Year, Workspace and the filter rows stay as quick as they are.
  • Matching letters are highlighted, and each option keeps its help text and group heading.
  • Keys: ↓↑ move, Enter or Tab picks, Esc closes only the list. Typing on a focused closed control opens it with your letters already entered.
  • One text for the field: "Search" plus what is being picked, e.g. "Search types". An unmatched search says "No match".
  • Creating ("Create …") appears in the list only where a new value is allowed: people, groups, tasks.
